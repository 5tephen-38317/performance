# ✿ Cosmos — Math to Music Studio

**수학 그래프를 음악으로 연결하는 인터랙티브 그래핑 계산기**

Cosmos는 사용자가 직접 함수식을 입력하고 그래프의 변화를 관찰할 수 있는 웹 기반 그래핑 계산기입니다. 일반적인 그래프 시각화 기능에서 더 나아가, 그래프의 움직임을 소리로 표현하는 오디오 추적 기능을 결합하여 수학과 음악을 연결하는 것을 목표로 개발하고 있습니다.

---

## 1. 프로젝트 소개

수학에서 함수는 식으로 표현되지만, 그 식이 실제로 어떤 그래프를 만들어 내는지 이해하려면 시각적인 관찰이 중요합니다.

Cosmos는 이러한 함수의 변화를 그래프로 확인하고, 그래프와 음악을 연결하여 수학적 개념을 다양한 감각으로 경험할 수 있도록 기획한 프로젝트입니다.

단순히 그래프를 그리는 계산기를 넘어 수학적 표현을 음악적 표현으로 확장하는 통합형 그래핑 환경을 만드는 것이 프로젝트의 목표입니다.

## 2. 주요 기능

### ① 함수 입력 및 그래프 시각화
- 함수식을 직접 입력하여 그래프를 확인할 수 있습니다.
- 여러 함수를 입력하고 그래프의 형태를 비교할 수 있도록 구성하고 있습니다.
- 그래프를 통해 함수의 변화와 특징을 관찰할 수 있습니다.

### ② 수학 가상 키패드
- 숫자와 연산자, 문자 등을 입력할 수 있습니다.
- 분수, 지수, 제곱근, 삼각함수 등 수학 기호 입력을 지원하도록 개발하고 있습니다.
- ABC 입력 모드와 123 입력 모드를 분리하여 수식 입력을 편리하게 만드는 것을 목표로 합니다.

### ③ 그래프 레이어
- 여러 함수를 개별적으로 관리할 수 있도록 구성하고 있습니다.
- 여러 그래프를 함께 표시하여 함수 사이의 관계를 비교할 수 있습니다.

### ④ 오디오 추적(Audio Tracking)
- 그래프의 움직임을 소리로 표현하는 기능입니다.
- 그래프와 음악을 연결하여 수학적 변화를 청각적으로 경험할 수 있도록 개발하고 있습니다.
- 음계, 템포, 악기 등의 음악 설정을 확장하고 있습니다.

### ⑤ 그래프 저장 및 공유
- 작성한 그래프를 저장하고 다시 불러오는 기능을 개발하고 있습니다.
- 그래프 정보를 다른 사용자와 공유할 수 있는 기능을 구현하고 있습니다.

### ⑥ 회원가입 및 로그인
- Supabase 인증을 활용하여 사용자 계정을 관리하는 기능을 개발하고 있습니다.
- 메인 그래프 계산기와 회원가입 페이지를 별도의 페이지로 구성하고 있습니다.

---

## 3. 사용 방법

1. 배포된 Cosmos 웹사이트에 접속합니다.
2. 함수 입력 영역에 원하는 함수식을 입력합니다.
3. 그래프 영역에서 함수의 형태와 변화를 관찰합니다.
4. 가상 키패드를 이용하여 필요한 수학 기호와 문자를 입력합니다.
5. 오디오 추적 기능을 이용하여 그래프와 소리의 관계를 확인합니다.
6. 그래프 레이어를 활용하여 여러 함수의 그래프를 비교합니다.

※ 일부 기능은 현재 개발 및 테스트 중이며, 실제 배포 환경에서의 정상 작동 여부를 확인하고 있습니다.

## 5. 프로젝트 실행 방법

### ① 저장소 복제

```bash
git clone https://github.com/5tephen-38317/my-first-lab.git
```

### ② 프로젝트 폴더 이동

```bash
cd my-first-lab
```

### ③ 필요한 라이브러리 설치

프로젝트에서 사용하는 라이브러리를 설치합니다.

```bash
pip install streamlit
```

※ 추가 라이브러리가 필요한 경우 해당 패키지도 설치해야 합니다.

### ④ 프로그램 실행

```bash
streamlit run main.py
```

명령어를 실행하면 로컬 웹 브라우저에서 Cosmos를 확인할 수 있습니다.

## 7. 개발 현황 및 향후 계획

현재 Cosmos는 기본 그래프 계산 환경을 중심으로 키패드와 오디오 추적 기능을 확장하고 있습니다.

앞으로 다음 기능을 개선할 계획입니다.

- 수학 키패드의 입력 방식과 화면 배치를 개선하여 수식 입력의 편의성 향상
- 키패드와 오디오 추적 패널의 독립적인 작동 보장
- 그래프 파일 저장 및 불러오기 기능의 안정화
- 그래프 공유 링크 생성 및 복원 기능 검증
- 슬라이더의 변수 변경이 함수식과 그래프에 반영되도록 개선
- 회원가입 페이지와 메인 그래핑 계산기의 인증 세션 연결
- 다양한 음계와 악기를 활용한 음악 생성 기능 확장

Cosmos는 수학적 표현을 시각적·청각적으로 확장하여 함수와 그래프를 새로운 방식으로 탐구할 수 있는 환경을 만드는 것을 목표로 합니다.
