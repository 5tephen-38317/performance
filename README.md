# Cosmos

## 1. 프로젝트 소개

Cosmos는 수학 함수의 그래프를 시각화하고 그래프의 형태를 음악으로 변환할 수 있도록 제작한 웹 애플리케이션이다. 사용자가 직접 함수를 입력하면 해당 함수의 그래프를 좌표평면에 나타내며, 그래프의 값을 음높이와 연결하여 그래프의 개형에 따른 음악을 생성할 수 있도록 구현하였다.

## 2. 사용법

1. 함수 입력창에 원하는 수학 함수를 입력한다.
2. 그래프 그리기 기능을 실행하여 입력한 함수의 그래프를 확인한다.
3. 그래프를 드래그하여 화면을 이동하거나 마우스 휠을 이용하여 확대·축소할 수 있다.
4. 화면에 제공되는 수학 키패드를 이용하여 함수식을 직접 입력할 수 있다.
5. 그래프 분석 영역에서 함수의 정의역, 최솟값, 최댓값, 평균값 등의 정보를 확인한다.
6. 원하는 음계와 템포를 선택한다.
7. 그래프를 음악으로 변환하는 기능을 실행한다.
8. 음악이 재생되는 동안 그래프 위의 점이 왼쪽에서 오른쪽으로 이동하며 현재 재생 위치를 나타낸다.

## 3. 주요 기능

### 함수 입력 및 그래프 시각화

사용자가 입력한 수학 함수를 좌표평면에 그래프로 나타낸다. 키보드뿐만 아니라 화면에 제공되는 수학 키패드를 통해서도 함수식을 입력할 수 있다.

### 그래프 화면 조작

그래프를 확대하거나 축소할 수 있으며, 그래프 영역을 드래그하여 좌우 및 상하로 화면을 이동할 수 있다. 초기 화면으로 되돌리는 기능도 제공한다.

### 그래프 분석

입력된 함수의 그래프를 분석하여 정의역, 최솟값, 최댓값, 평균값 및 그래프의 전반적인 변화 방향을 확인할 수 있다.

### 그래프 기반 음악 생성

그래프의 x축 방향을 시간의 흐름으로 대응시키고, 함수의 y값을 음높이로 변환하여 그래프의 형태에 따라 음악을 생성한다.

### 음악 재생 위치 시각화

음악이 재생되는 동안 그래프 위에 점을 표시하고 화면의 왼쪽에서 오른쪽으로 이동시켜 현재 음악이 재생되고 있는 그래프의 위치를 시각적으로 나타낸다.

### 음계 및 템포 설정

사용자가 원하는 음계와 재생 속도를 선택하여 그래프를 서로 다른 음악으로 변환할 수 있다.
